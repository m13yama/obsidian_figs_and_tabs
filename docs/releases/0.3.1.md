This beta release makes figure and grid Markdown easier to edit in Source mode and expanded Live Preview callouts.

## Changes

- Highlight `grid`, `figure`, and `table` headers and mark their source lines with a continuous background.
- Display Mermaid and other fenced code inside callouts with a block background, fixing the separate inline-code backgrounds previously applied to each line.
- Remove quotation borders from layout source while keeping `>` markers visible for editing.
- Follow the light and dark theme. Preserve ordinary quotes, other callout types, real inline code, and emphasis.
- Track nested callout and code-fence boundaries across the document, including lines outside the viewport. Remove editor decorations when the plugin is disabled.

The Markdown syntax, Mermaid width controls, and rendered grids are unchanged. No note or settings migration is required from 0.3.0 or 0.2.0.

## Installation and updates

1. Download `figures-and-tables-0.3.1.zip` from Assets and extract it.
2. Copy the `figures-and-tables` folder into your vault's `.obsidian/plugins/` directory. When updating, replace `main.js`, `manifest.json`, and `styles.css`, and keep your `data.json` settings file.
3. Disable and re-enable **Figures and Tables** under **Settings → Community plugins**, or reload Obsidian, to load the editor changes.

You can also download the three plugin files individually from Assets. The "Source code" ZIP does not include the built plugin.

See the [README](https://github.com/m13yama/obsidian_figs_and_tabs/blob/0.3.1/README.md) for syntax and usage, and [examples](https://github.com/m13yama/obsidian_figs_and_tabs/tree/0.3.1/examples) for sample notes.

## Verification and beta scope

- Type checking, the production build, and all 37 unit tests pass.
- Tested with Obsidian 1.12.7 on Linux using the default theme: Source mode and expanded Live Preview styling in light and dark themes, inline formatting preservation, cursor positions, typing, Undo, and disabling/re-enabling the plugin.
- Existing integration checks pass for Reading view and Live Preview, Mermaid diagrams and widths, mixed image/table grids, captions, spacing, spans, horizontal scrolling, and editing commands.
- Physical mobile devices, PDF export, and community themes have not been tested.

The plugin version and tag are `0.3.1` for Obsidian compatibility. This release is marked as a GitHub prerelease.
