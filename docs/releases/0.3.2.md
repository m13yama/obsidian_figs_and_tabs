This beta release makes Mermaid source inside grids and figures look like a normal Obsidian code block, with a different background to distinguish nesting.

## Changes

- Use Obsidian's native code-block font, spacing, and rounded corners for Mermaid and other fenced code inside layout callouts.
- Remove the extra top, bottom, and left borders previously added to these code blocks, and replace quotation indentation with code-block spacing.
- Keep a distinct background for nested code in light and dark themes, with visible quote markers and highlighted layout headers.

These changes apply to Source mode and expanded Live Preview callouts. Existing Markdown, diagram widths, grids, and settings continue to work without migration from 0.2.0 or 0.3.x.

## Installation and updates

1. Download `figures-and-tables-0.3.2.zip` from Assets and extract it.
2. Copy the `figures-and-tables` folder into your vault's `.obsidian/plugins/` directory. When updating, replace `main.js`, `manifest.json`, and `styles.css`, and keep your `data.json` settings file.
3. Disable and re-enable **Figures and Tables** under **Settings → Community plugins**, or reload Obsidian, to load the editor changes.

You can also download the three plugin files individually from Assets. The "Source code" ZIP does not include the built plugin.

See the [README](https://github.com/m13yama/obsidian_figs_and_tabs/blob/0.3.2/README.md) for syntax and usage, and [examples](https://github.com/m13yama/obsidian_figs_and_tabs/tree/0.3.2/examples) for sample notes.

## Verification and beta scope

- Type checking, the production build, and all 37 unit tests pass.
- Compared nested Mermaid with ordinary code blocks in Obsidian 1.12.7 on Linux using the default theme, in Source mode and expanded Live Preview, in light and dark themes.
- Verified distinct nested backgrounds, highlighted headers, ordinary quotes and inline formatting, typing, Undo, and plugin disabling/re-enabling.
- Existing integration checks pass for Reading view and Live Preview, Mermaid rendering and widths, image/table grids, captions, spacing, spans, horizontal scrolling, and editing commands.
- Physical mobile devices, PDF export, and community themes have not been tested.

The plugin version and tag are `0.3.2` for Obsidian compatibility. This release is marked as a GitHub prerelease.
