This beta release aligns figures to the bottom and tables to the top of each grid row.

## Changes

- Bottom-align figures within each row, including their captions, so figures of different heights share a lower edge.
- Keep tables aligned to the top of each row, including their captions.
- Apply the same alignment to captionless images, Mermaid diagrams, and tables in Reading view and Live Preview, including narrow panes with horizontal scrolling.

Caption positions, Markdown syntax, widths, spacing, and column spans remain unchanged. No note or settings migration is required from 0.2.0 or 0.3.x.

## Installation and updates

1. Download `figures-and-tables-0.3.3.zip` from Assets and extract it.
2. Copy the `figures-and-tables` folder into your vault's `.obsidian/plugins/` directory. When updating, replace `main.js`, `manifest.json`, and `styles.css`, and keep your `data.json` settings file.
3. Disable and re-enable **Figures and Tables** under **Settings → Community plugins**, or reload Obsidian.

You can also download the three plugin files individually from Assets. The "Source code" ZIP does not include the built plugin.

See the [README](https://github.com/m13yama/obsidian_figs_and_tabs/blob/0.3.3/README.md) for syntax and usage, and [examples](https://github.com/m13yama/obsidian_figs_and_tabs/tree/0.3.3/examples) for sample notes.

## Verification and beta scope

- Type checking, the production build, and all 37 unit tests pass.
- Verified figure bottom alignment and table top alignment in Obsidian 1.12.7 on Linux using the default theme, in Reading view and Live Preview, at wide and narrow pane widths.
- Checked captioned and captionless items, mixed figure/table rows, images with explicit widths, and Mermaid code blocks and note/block embeds.
- Existing integration checks pass for captions, spacing, spans, horizontal scrolling, Mermaid sizing, source styling, light/dark themes, editing commands, Undo, and plugin disabling/re-enabling.
- Physical mobile devices, PDF export, and community themes have not been tested.

The plugin version and tag are `0.3.3` for Obsidian compatibility. This release is marked as a GitHub prerelease.
