This beta release adds Mermaid diagrams to figure grids and supports Obsidian-style widths for diagram embeds.

## Changes

- Arrange Mermaid code blocks side by side inside a `grid`, with or without figure captions. Mix diagrams with images and tables.
- Size Mermaid-only note and block embeds with `![[fig_name|300]]` and `![[fig_name#^flow|450]]` inside a `grid` or `figure`.
- Set the width of a Mermaid code block inside a figure with `[!figure|width=300]`. An embed's own width takes priority over the figure's width.
- Preserve diagram aspect ratios and intrinsic sizes when no width is specified. Grids retain the requested widths and scroll horizontally in narrow panes.
- Remove extra embed padding and internal scrollbars from diagram-only embeds so diagrams remain fully visible.
- Keep native Mermaid SVGs and links intact, update after delayed rendering and width edits, and restore native styling when the plugin is disabled.
- Add Mermaid example notes and document both width syntaxes.

## Example

Put a Mermaid code block in `fig_name.md`, then embed it at different widths:

```markdown
> [!grid|cols=2 lgap=24 vgap=16]
> ![[fig_name|300]]
>
> > [!figure] The same diagram at 450px
> > ![[fig_name|450]]
```

Widths are positive integers in pixels. The leading `!` embeds the diagram. Note and block embeds must contain only figure content including Mermaid; notes containing explanatory text retain their normal embed layout. Width support applies inside `grid` and `figure` callouts.

## Installation and updates

1. Download `figures-and-tables-0.3.0.zip` from Assets and extract it.
2. Copy the `figures-and-tables` folder into your vault's `.obsidian/plugins/` directory. When updating, replace the existing `main.js`, `manifest.json`, and `styles.css` files in that folder and keep your `data.json` settings file.
3. Reload Obsidian and enable **Figures and Tables** under **Settings → Community plugins**.

You can also download the three files individually from Assets. The "Source code" ZIP does not include the built plugin.

No note or settings migration is required from 0.2.0. If upgrading from 0.1.0, replace the old `gap` option with `lgap` and `vgap` as described in the README.

See the [README](https://github.com/m13yama/obsidian_figs_and_tabs/blob/0.3.0/README.md) for syntax and usage, and [Mermaid examples](https://github.com/m13yama/obsidian_figs_and_tabs/blob/0.3.0/examples/mermaid-and-grids.md) for sample notes.

- Tested with Obsidian 1.12.7 on Linux using the default theme: Reading view and Live Preview, inline Mermaid, note and block embeds, explicit widths, aspect ratios, width edits, horizontal scrolling, and disabling/re-enabling the plugin.
- Existing image/table grids, spacing, captions, spans, editing commands, and Undo pass the integration tests. Figure and table styles are also compared with ordinary content in light and dark modes and with customized table borders.
- Physical mobile devices, PDF export, and community themes have not been tested.
