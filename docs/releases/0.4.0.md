This beta release integrates video sizing into Figures and Tables and adds video support to grids.

## Changes

- Size embedded videos with Obsidian's image-style syntax: `![[movie.mp4|640]]` or `![[movie.mp4|640x360]]`.
- Support `mp4`, `webm`, `ogv`, `mov`, and `mkv` embeds in Reading view and Live Preview.
- Treat captionless videos placed directly inside a `grid` as figure items.
- Support videos inside captioned `figure` callouts, including column spans and the existing bottom alignment.
- Preserve authored video widths in horizontally scrolling grids while scaling standalone videos down to fit narrow containers.
- Observe delayed native video rendering and dimension changes without replacing Obsidian's video nodes or handlers.
- Remove all video classes and inline sizing owned by the plugin when it is disabled.

No note or settings migration is required from 0.2.0 or 0.3.x. If the separate **Movie Size** plugin is installed, disable or remove it after updating because its functionality is now included in **Figures and Tables**.

## Installation and updates

1. Download `figures-and-tables-0.4.0.zip` from Assets and extract it.
2. Copy the `figures-and-tables` folder into your vault's `.obsidian/plugins/` directory. When updating, replace `main.js`, `manifest.json`, and `styles.css`, and keep your `data.json` settings file.
3. Disable and re-enable **Figures and Tables** under **Settings → Community plugins**, or reload Obsidian.

You can also download the three plugin files individually from Assets. The "Source code" ZIP does not include the built plugin.

See the [README](https://github.com/m13yama/obsidian_figs_and_tabs/blob/0.4.0/README.md) for syntax and usage, and [examples](https://github.com/m13yama/obsidian_figs_and_tabs/tree/0.4.0/examples) for grids and captions.

## Verification and beta scope

- Added unit coverage for video dimension parsing, supported extensions, fallback attributes, delayed rendering, dimension changes, overlapping render roots, cleanup, and bare videos in grids.
- Existing coverage remains in place for options, editing transformations, source boundaries, native-node preservation, captions, grids, Mermaid sizing, and renderer cleanup.
- Physical mobile devices, PDF export, and community themes have not been tested.

The plugin version and tag are `0.4.0` for Obsidian compatibility. This release is marked as a GitHub prerelease.
