This beta release centers figures and tables in columns sized to their content and supports mixing items with and without captions.

## Changes

- Write Markdown tables and images directly inside a `grid` to arrange them side by side. Mix them with captioned `figure` and `table` callouts.
- Size columns to their content and center the entire grid. Narrow panes retain the columns and allow horizontal scrolling from the left edge.
- Set horizontal spacing with `lgap` and vertical spacing with `vgap`. Both accept 0–96px and default to 16px. The settings screen and grid creation command support both options.
- Remove callout backgrounds, borders, and tinting so table borders and text inherit the note's settings. Figure and table captions remain centered.
- Preserve image widths, including SVGs, and honor explicit widths such as `![[image.png|300]]`.

## Upgrading from 0.1.0

The old `gap` option has been removed. There is no compatibility fallback or automatic note migration.

```markdown
Before: > [!grid|cols=2 gap=16]
After:  > [!grid|cols=2 lgap=16 vgap=16]
```

To keep the previous horizontal and vertical spacing, set both `lgap` and `vgap` to the old `gap` value. The saved `gap` setting is not migrated either. If you customized the default spacing, set the new defaults in the plugin settings.

## Example

```markdown
> [!grid|cols=2 lgap=24 vgap=16]
> | Diameter | Ampacity |
> | --- | --- |
> | 1.6 mm | 27 A |
> | 2.0 mm | 35 A |
>
> > [!table] Cross-sectional area and ampacity
> > | Area | Ampacity |
> > | --- | --- |
> > | 2.0 mm² | 27 A |
> > | 3.5 mm² | 37 A |

This paragraph is outside the grid.
```

## Installation and updates

1. Download `figures-and-tables-0.2.0.zip` from Assets and extract it.
2. Copy the `figures-and-tables` folder into your vault's `.obsidian/plugins/` directory. When updating, replace the existing `main.js`, `manifest.json`, and `styles.css` files in that folder.
3. Reload Obsidian and enable **Figures and Tables** under **Settings → Community plugins**.

You can also download the three files individually from Assets. The "Source code" ZIP does not include the built plugin.

See the [README](https://github.com/m13yama/obsidian_figs_and_tabs/blob/0.2.0/README.md) for syntax and usage, and [examples](https://github.com/m13yama/obsidian_figs_and_tabs/tree/0.2.0/examples) for sample notes and images.

## Verification and beta scope

- Type checking, the production build, and all 27 unit tests pass.
- Tested with Obsidian 1.12.7 on Linux using the default theme: Reading view, Live Preview, mixed captions, centered grids sized to their content, horizontal and vertical spacing, image widths, spans, horizontal scrolling, table edits, commands and Undo, and disabling/re-enabling the plugin.
- Compared figure and table styles with ordinary note content in light and dark modes and with customized table border colors.
- Physical mobile devices, PDF export, and community themes have not been tested.

The plugin version and tag are `0.2.0` for Obsidian compatibility. This release is marked as a GitHub prerelease.
