This beta release fixes the alignment of sized standalone videos.

## Changes

- Center videos sized with syntax such as `![[movie.mp4|500]]` when they are embedded directly in a note.
- Keep the existing centered alignment for videos inside `figure` and `grid` callouts.
- Add a regression test for the standalone video display and margins.

No note or settings migration is required from 0.2.0 through 0.4.0.

## Installation and updates

1. Download `figures-and-tables-0.4.1.zip` from Assets and extract it.
2. Copy the `figures-and-tables` folder into your vault's `.obsidian/plugins/` directory. When updating, replace `main.js`, `manifest.json`, and `styles.css`, and keep your `data.json` settings file.
3. Disable and re-enable **Figures and Tables** under **Settings → Community plugins**, or reload Obsidian.

You can also download the three plugin files individually from Assets. The "Source code" ZIP does not include the built plugin.

See the [README](https://github.com/m13yama/obsidian_figs_and_tabs/blob/0.4.1/README.md) for syntax and usage, and [examples](https://github.com/m13yama/obsidian_figs_and_tabs/tree/0.4.1/examples) for grids and captions.

## Verification and beta scope

- Unit tests, type checking, and the production build run before the release is published.
- Physical mobile devices, PDF export, and community themes have not been tested.

The plugin version and tag are `0.4.1` for Obsidian compatibility. This release is marked as a GitHub prerelease.
