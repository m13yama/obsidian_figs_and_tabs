This beta release makes figure and table captions use the same text color as the surrounding note.

## Changes

- Inherit the surrounding text color for figure and table captions instead of using a muted color.

No note or settings migration is required from 0.2.0 or 0.3.x.

## Installation and updates

1. Download `figures-and-tables-0.3.4.zip` from Assets and extract it.
2. Copy the `figures-and-tables` folder into your vault's `.obsidian/plugins/` directory. When updating, replace `main.js`, `manifest.json`, and `styles.css`, and keep your `data.json` settings file.
3. Disable and re-enable **Figures and Tables** under **Settings → Community plugins**, or reload Obsidian.

You can also download the three plugin files individually from Assets. The "Source code" ZIP does not include the built plugin.

See the [README](https://github.com/m13yama/obsidian_figs_and_tabs/blob/0.3.4/README.md) for syntax and usage, and [examples](https://github.com/m13yama/obsidian_figs_and_tabs/tree/0.3.4/examples) for sample notes.

## Verification and beta scope

- Type checking, the production build, and all 37 unit tests pass.
- Checked caption color inheritance with light and dark text colors.
- Existing Obsidian integration checks pass for Reading view, Live Preview, grid alignment, captions, spacing, Mermaid sizing, source styling, light/dark themes, editing commands, Undo, and plugin disabling/re-enabling.
- Physical mobile devices, PDF export, and community themes have not been tested.

The plugin version and tag are `0.3.4` for Obsidian compatibility. This release is marked as a GitHub prerelease.
