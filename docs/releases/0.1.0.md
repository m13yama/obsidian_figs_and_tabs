The first beta release of Figures and Tables.

## Features

- Add captions with `figure` and `table` callouts. Both captions are centered, appearing below figures and above tables by default.
- Arrange figures and tables side by side or in a grid with a `grid` callout. Configure the column count, spacing, and column spans.
- Keep the configured columns in narrow panes and scroll the entire grid horizontally. Each column has a minimum width of 240px.
- Supports Reading view and Live Preview.
- Includes commands for creating figures, tables, and grids, changing the column count, and settings for caption positions and spacing.

```markdown
> [!grid|cols=2 gap=16]
> > [!figure] Experimental apparatus
> > ![[apparatus.png]]
>
> > [!table] Measurement conditions
> > | Item | Value |
> > | --- | --- |
> > | Temperature | 25°C |

This paragraph is outside the grid.
```

## Installation

1. Download `figures-and-tables-0.1.0.zip` from Assets and extract it.
2. Copy the `figures-and-tables` folder into your vault's `.obsidian/plugins/` directory.
3. Reload Obsidian and enable **Figures and Tables** under **Settings → Community plugins**.

You can also download `main.js`, `manifest.json`, and `styles.css` individually and place them in `.obsidian/plugins/figures-and-tables/`. The "Source code" ZIP does not include the built plugin.

See the [README](https://github.com/m13yama/obsidian_figs_and_tabs/blob/0.1.0/README.md) for syntax and usage, and [examples](https://github.com/m13yama/obsidian_figs_and_tabs/tree/0.1.0/examples) for sample notes and images.

## Verification and beta scope

- Type checking, the production build, and all 21 unit tests pass.
- Tested with Obsidian 1.12.7 on Linux using the default theme: Reading view, Live Preview, horizontal scrolling, column spans, table edits, Undo, and disabling/re-enabling the plugin.
- Physical mobile devices, PDF export, and community themes have not been tested.
- Automatic numbering, cross-references, subfigure labels such as (a)/(b), and lists of figures and tables are not included.

The plugin version and tag are `0.1.0` for Obsidian compatibility. This release is marked as a GitHub prerelease.
